# Publishing and archiving

Keep this repository **private** until all coauthors approve public sharing of the manuscript and data. Confirm the unit of settleable solids (`SS_mL_L` in the dataset, `mg/L` in one manuscript version).

1. Add `data/Base_Datos_Calidad_Agua_Integrada.xlsx` through GitHub **Add file → Upload files**.
2. Optionally upload the latest coauthor-approved manuscript PDF to `docs/Nuxco_Manuscript_Preprint.pdf`.
3. Test the Colab notebook and Python script with the uploaded data.
4. Choose a license after confirming rights to the code, data and figures.
5. Verify citations/DOIs and confirm author order before public release.
6. For a stable dataset/code archive with a DOI, connect the GitHub release to Zenodo (or deposit separately in an appropriate data repository).

The repository should not be presented as a validated prospective forecasting product or as proof of pollution.
